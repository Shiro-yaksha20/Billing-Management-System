## 1. Executive Summary

### 1.1 Purpose

The Salon Billing System is a desktop application designed for small to medium-sized salons to manage their billing operations, customer relationships, and business reporting. The system provides an intuitive interface for creating bills, managing services, tracking customers, and generating professional PDF receipts with WhatsApp integration.

### 1.2 Target Users

| User Type | Description | Primary Needs |
|-----------|-------------|---------------|
| **Salon Owner** | Business owner managing the salon | Reports, settings, backups |
| **Receptionist** | Front desk staff handling billing | Quick billing, customer lookup |
| **Stylist/Staff** | Service providers | View assigned bills |

### 1.3 Key Value Propositions

- ? **Offline-First**: Works without internet, syncs when connected
- ? **Professional Receipts**: Branded PDF receipts with QR codes
- ? **WhatsApp Integration**: Send receipts directly to customers
- ? **Clean Architecture**: Maintainable, testable, extensible codebase
- ? **Data Security**: Encrypted backups with cloud storage option

## 2. Product Overview

### 2.1 Problem Statement

Small salons face challenges with:
- Manual billing leading to errors and slow service
- No customer history tracking for personalized service
- Difficulty generating professional receipts
- No backup/recovery for business data
- Limited reporting for business insights

### 2.2 Solution

A comprehensive desktop billing system that:
- Streamlines the billing process with an intuitive UI
- Maintains complete customer history and preferences
- Generates professional branded receipts
- Provides automated WhatsApp delivery
- Ensures data safety with encrypted backups

### 2.3 Success Metrics

| Metric | Target | Measurement |
|--------|--------|-------------|
| Bill Creation Time | < 30 seconds | From customer selection to save |
| Receipt Delivery | < 5 seconds | PDF generation + WhatsApp send |
| System Uptime | 99.9% | Application stability |
| Data Recovery | 100% | Successful backup restoration |

### 3.2 Layer Responsibilities

| Layer | Responsibility | Allowed Dependencies |
|-------|----------------|---------------------|
| **UI** | Render data, capture input, show messages | Services, DTOs, Exceptions |
| **Services** | Business logic, validation, orchestration | Repositories, Infrastructure, DTOs |
| **Repositories** | CRUD operations, queries | Models, Database |
| **Infrastructure** | External systems (PDF, cloud, crypto) | External libraries only |
| **Models** | Data structure definition | SQLAlchemy only |
| **DTOs** | Data transfer between layers | Nothing (plain data) |

### 6.3 Database Schema

```sql
-- Customers
CREATE TABLE customers (
    id INTEGER PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    phone VARCHAR(20) UNIQUE NOT NULL,
    notes TEXT,
    last_visit_at DATETIME,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- Staff
CREATE TABLE staff (
    id INTEGER PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    phone VARCHAR(20),
    role VARCHAR(50),
    active BOOLEAN DEFAULT TRUE,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- Services
CREATE TABLE services (
    id INTEGER PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    display_name VARCHAR(100),
    description TEXT,
    category VARCHAR(50),
    price DECIMAL(10,2),
    duration_minutes INTEGER,
    notes TEXT,
    active BOOLEAN DEFAULT TRUE,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- Bills
CREATE TABLE bills (
    id INTEGER PRIMARY KEY,
    bill_number VARCHAR(20) UNIQUE,
    customer_id INTEGER REFERENCES customers(id),
    staff_id INTEGER REFERENCES staff(id),
    bill_datetime DATETIME DEFAULT CURRENT_TIMESTAMP,
    subtotal DECIMAL(10,2),
    discount_type VARCHAR(10),
    discount_value DECIMAL(10,2),
    discount_amount DECIMAL(10,2),
    tax_percent DECIMAL(5,2),
    tax_amount DECIMAL(10,2),
    total DECIMAL(10,2),
    payment_method VARCHAR(20),
    transaction_id VARCHAR(100),
    payment_status VARCHAR(20) DEFAULT 'Paid',
    pdf_path VARCHAR(500),
    whatsapp_status VARCHAR(20),
    whatsapp_error TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- Bill Items
CREATE TABLE bill_items (
    id INTEGER PRIMARY KEY,
    bill_id INTEGER REFERENCES bills(id),
    service_id INTEGER REFERENCES services(id),
    service_name VARCHAR(100),
    quantity INTEGER DEFAULT 1,
    unit_price DECIMAL(10,2),
    line_total DECIMAL(10,2)
);

-- Settings
CREATE TABLE settings (
    id INTEGER PRIMARY KEY,
    key VARCHAR(100) UNIQUE NOT NULL,
    value TEXT
);
```
