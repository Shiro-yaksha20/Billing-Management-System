## 11. Coding Standards & Rules

> **IMPORTANT**: All UI implementations MUST follow these rules from the project's clean architecture.

### 11.1 ?? Absolute Architecture Rules (NEVER VIOLATE)

| Rule ID | Rule | Description | Consequence |
|---------|------|-------------|-------------|
| **R1** | UI NEVER imports `db_session` | UI classes must not access database directly | Breaks testability |
| **R2** | UI NEVER imports ORM models for queries | No direct model queries in UI | Tight coupling |
| **R3** | Services NEVER import PyQt6 | Services must be UI-agnostic | Can't unit test |
| **R4** | Repositories contain NO business logic | Only CRUD operations | Wrong responsibility |
| **R5** | All business rules live in Services | Single source of truth | Duplicated logic |
| **R6** | Infrastructure modules are stateless adapters | No state, side-effect free | Hard to test |

        """
        Get statistics for the dashboard.
        
        Returns:
            DashboardStats with today's metrics and recent bills.
        """
        today = date.today()
        today_start = datetime.combine(today, datetime.min.time())
        today_end = datetime.combine(today, datetime.max.time())
        
        # Get today's bills
        today_bills = self._bill_repo.find_by_date_range(today_start, today_end)
        
        # Calculate stats
        today_sales = sum(b.total for b in today_bills if b.payment_status == "Paid")
        pending_bills = [b for b in today_bills if b.payment_status == "Pending"]
        
        # Get recent bills (last 5)
        recent_bills = self._bill_repo.find_recent(limit=5)
        
        # Unique customers today
        customer_ids = {b.customer_id for b in today_bills}
        
        return DashboardStats(
            today_sales=today_sales,
            today_bills_count=len(today_bills),
            pending_amount=sum(b.total for b in pending_bills),
            pending_count=len(pending_bills),
            today_customers=len(customer_ids),
            recent_bills=[self._to_dto(b) for b in recent_bills],
        )
